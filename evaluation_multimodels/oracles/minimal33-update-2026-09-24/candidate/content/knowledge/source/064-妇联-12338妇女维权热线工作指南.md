# 12338  妇女维权热线工作指南（试行本）

## 前言

保障妇女儿童权益是人权保障的重要内容，是国际社会高度关注的重要领域。联合国长期致力于推动《消除对妇女一切形式歧视公约》和《儿童权利公约》精神在各国的传播和实施。中国政府作为两个公约的缔约国，始终高度重视维护妇女儿童权益的工作。中共十八大将＂坚持男女平等基本国策，保障妇女儿童合法权益＂作为重要的施政纲领，已基本形成以《宪法》为依据，以《妇女权益保障法》、《未成年人保护法》为主体的保障妇女儿童合法权益的法律体系，各级政府将性别平等、儿童优先在内的公平正义作为构建社会主义和谐社会的重要内容，大力实施中国妇女、儿童发展纲要（2011－2020），逐步优化妇女儿童人权保障的社会环境，促进妇女儿童的全面发展。

＂代表和维护妇女权益，促进男女平等＂是妇联组织的基本职能。为了更好联系和服务妇女，畅通妇女儿童维权渠道，全国妇联在 2800多个县（区）开通了12338妇女维权服务热线，在全国农村、社区和一些女性集中的领域建立＂妇女之家＂ 74.5 万个，妇女儿童维权合议庭、维权站、维权岗、家庭暴力投诉站等 25 万个。为了进一步完善热线和妇女之家的维权服务功能，全国妇联权益部在联合国儿基会的支持下，开发编写了《12338妇女维权热线工作指南》和《妇女之家维权服务指南》，旨在通过理念方法介绍，操作流程指引，帮助妇联组织的热线工作者和妇女之家工作人员提高性别意识和儿童视角，掌握实用技能，规范服务行为，在贯彻落实男女平等基本国策，维护家庭和谐促进社会稳定方面，发挥更大作用。

《12338妇女维权热线工作指南》和《妇女之家维权服务指南》的开发凝聚了专家团队和项目工作人员的心血，总结提炼了各地基层开展维权工作的成功实践和经验做法，组织了多次不同范围的研讨论证，经过了天津、湖北、江苏、云南四个省市妇联权益部的调研、开发、培训和试用，提供了社区儿童保护服务和热线咨询方面的一些国际经验，从其理论性、权威性和可操作性上看，是一套适合基层妇联干部、热线工作者和妇女之家工作人员使用，实用、管用的工具参考书。

考虑到中国地区间经济社会发展不平衡，文化传统与风俗习惯差异较大等因素，指南预留出一定的篇幅和空间，供各地结合本地实际进一步补充开发，体现出因地制宜的特点。希望广大基层维权干部、热线工作者和妇女之家工作人员能够真正将两本指南用起来，为妇联基层维权服务提供更多更好的实践经验，不断充实完善指南的内容，使基层妇女儿童能够获得实实在在、快捷便利的维权服务。

推动将男女平等基本国策、儿童优先理念和儿童保护原则从法律变为现实，是一项长期的系统的工程，需要全社会的共同努力，需要更加深入细致的工作。让我们携起手来，共同行动，为保障妇女儿童权益做出不懈的努力！

蒋月娥 女士（全国妇联权益部部长、全国妇联法律帮助中心主任）

## 第一部分 热线操作

### 综合篇

#### 一、12338热线工作的基本理念

12338妇女维权热线（简称＂12338热线＂）是妇联组织的基层工作载体，直接服务妇女儿童，应当在维护妇女儿童权益的过程中坚定妇联组织的立场和主张，坚持以下基本理念：

（一）男女平等

＂妇女和男子在政治、经济、文化、社会和家庭生活各方面享有同等权利＂是我国宪法明确规定的基本原则，作为联合国《消除对妇女一切形式歧视公约》的缔约国，实行＂男女平等基本国策＂是1995年在北京召开的世界妇女大会上中国政府对国际社会提出的郑重承诺，也是2005年修改的《妇女权益保障法》中的明文规定。2012年党的十八大报告中明确提出要＂坚持男女平等基本国策，保障妇女儿童合法权益＂。12338热线工作者应当带头宣传贯彻男女平等基本国策，树立社会性别意识，促进两性平等和谐地发展。

（二）儿童优先

《儿童权利公约》确立了儿童优先、儿童最大利益原则。中国是《儿童权利公约》的缔约国，2006年修改的《未成年人保护法》规定：
＂未成年人享有生存权、发展权、受保护权、参与权等权利，国家根据未成年人身心发展特点给予特殊、优先保护，保障未成年人的合法权益不受侵犯。＂保护未成年人，是国家机关、武装力量、政党、社会团体、企业事业组织、城乡基层群众性自治组织、未成年人的监护人和其他成年公民的共同责任。对侵犯未成年人合法权益的行为，任何组织和个人都有权予以劝阻、制止或者向有关部门提出检举或者控告。12338热线工作者应当将保护儿童权益作为重要工作职责。

（三）助人自助

助人自助是现代社会开展社会工作的基本理念，强调在帮助别人的过程中，相信每个人的面临的问题和解决问题的办法都是独特的，相信求助者本人具有潜在的能力。助人者要做的不是教训他人，而是开导他人，不是包办代替，而是减少求助者的依赖性，增强他们的独立性和自主性，启发他们用自己的意志，开发自己的潜在能力，解决自己面临的问题。12338热线工作人员在开展维权服务时，应当更注重传递关爱和信心，注重挖掘求助者的潜能，帮助求助者自主决策，做掌握自己幸福命运的主人。

#### 二、12338 热线维权服务目标

12338热线的服务对象是妇女、儿童和其他有需要的来电者，服务目标是：

（一） 解疑释惑——提供及时、便捷的维权咨询服务
（二） 依法维权——形成典型侵权个案的快速处理和转介机制
（三） 分析预警——倾听妇女意愿呼声，分析掌握妇女权益重点问题和动态信息
（四） 化解矛盾——发现和化解基层矛盾纠纷，促进社会稳定
（五） 宣传倡导——宣传男女平等基本国策，普及维护妇女权益的法律知识

#### 三、12338 热线工作制度

热线应建立一套有效的工作制度，以规范工作人员的行为，提高工作效率，保证热线持续健康的发展。至少包括以下制度：

1、热线保密制度

为来电者保守秘密是接线员最起码的职业道德，也是保障热线接听工作有效进行的基本要求。来电者的资料仅能在热线工作中使用，严禁任何人当做社会闲谈的话题或者个案举例；严禁将来电记录公开或允许他人进行查阅。

2、个案会议制度

热线应当定期召开个案会办会议，对热线日常工作情况进行汇报，并对热线工作中的重点难点问题进行会办，及时协调解决。在接线过程中遇到重点、疑难、复杂或突发性案件，可不定期召开案件专题讨论会，研究并制定案件的处理方案，安排专人解答办理，及时将问题和纠纷解决，防止矛盾激化。

3、紧急案件处理预案。

热线应当制定紧急案件处理预案，对如何处理热线来电中正在发生的自杀、家庭暴力、性侵害、绑架、拐卖等重大侵害案件，做出具体和可操作的规定，并明确责任人。

4、跟踪回访制度

热线对未能即时答复和办理结束的来电要建立跟踪责任制，明确接线员或管理员在工作流程中对案件处理情况有责任进行跟踪了解，掌握案件的处理过程、进展和结果，并反馈给来电者。

热线对来电者应进行有选择性的回访，可采取走出去与请进来相结合、拨打回访电话与实地调查相结合等多种方式全面收集信息，了解案件办理的实际效果，以及来电者对热线服务的满意度和评价，并对回访信息作详细记录，统一归档。

5、分析报告制度

为及时掌握热线动态，了解妇女儿童权益保护状况和面临问题，热线工作应与研究工作相结合。坚持每季度对热线工作进行小结，年终对热线工作进行全面总结、综合分析，定期向有关部门、上级妇联报送反映妇女儿童生存状况的数据和信息，为相关调研和领导决策提供依据。

6、人员培训和督导制度

为了保持热线的可持续健康发展、保障接线员、志愿者等人员的工作质量和身心健康，应针对不同类别人群制订培训和督导计划，规定考核指标，通过岗前培训、案例研讨、专题讲座、实务操作、心理疏导等多种形式，从理论知识、工作实践和心理健康三方面进行培训提高。

#### 四、12338 热线来电处理流程说明

一、接线员工作

1. 来电接听与记录
- **①拨打**：来电者拨打 **12338 热线**
- **②接听**：接线员接听来电
- **③记录**：接线员记录来电内容
- **④研判与分级**：接线员对来电内容进行研判，并分为**一级、二级、三级**

2. 一级（可当场处理）
一级情况由接线员**⑤解答**，具体分三种处理方式：

1. **答复咨询**：可直接当场答复来电者的咨询问题
2. **转接处理**：属于热线服务范围内但接线员不能当场答复的，可转接专家或志愿者；若无专家支持，可告知来电者查询后回复
3. **告知职能部门**：超出妇联职责范围的一般案件，告知来电者向有权机关提出，并告知相关职能部门联系方式

3. 二级（需初步回应并上报）
- 接线员对来电进行**初步回应**
- 然后**⑤上报**给管理员处理

4. 三级（紧急要件）
- **启动紧急要件处理预案**
- 同时与管理员进行**接线员协同处理**（对应流程图中"上报/接线员协同处理"箭头）

5. 回访与跟踪反馈
- **⑥跟踪反馈**：形成闭环，跟踪处理结果反馈
- **⑦回访**：接线员对来电者进行回访

二、管理员工作

管理员接收接线员上报的案件后进行**研判**，分为两大方向：

1. 职能范围外
- **转介其他部门**：转交至公安、司法、民政、法院、检察院、社区等其他机关或机构
- **接线员答复**：由接线员直接答复来电者

2. 职能范围内 → 分流处理
管理员对职能范围内的案件进行**分流**，分为四类：

| 分流方式 | 处理内容 |
|---------|---------|
| **自办** | 管理员直接自行办理 |
| **会办** | 转法律、心理相关专家、单位会办 |
| **交办** | 交办至下级妇联 |
| **转送** | 转送至妇联信访维权机构，或转妇联有关部门/报告上级妇联 |

三、整体流程闭环

```
来电者 → 12338热线 → 接线员接听/记录/研判分级
    ├─ 一级 → 接线员当场解答（咨询/转接/告知职能部门）
    ├─ 二级 → 初步回应 → 上报管理员 → 管理员研判
    │            ├─ 职能范围外 → 转介其他部门 / 接线员答复
    │            └─ 职能范围内 → 分流（自办/会办/交办/转送）
    └─ 三级 → 启动紧急预案 → 与管理员协同处理

最终 → 回访来电者 → 跟踪反馈（形成闭环）
```

－图中所称接线员，指实际接听热线、解答当事人提问的人员，包括专职接线员和兼职接线员（如志愿者）；所称管理员，指热线的组织者、管理者，一般是本级妇联权益部门的工作人员。
－管理者有时也可能担任接线员，特别是在市、县级层面，接线员与管理员往往合二为一，需要履行双重职责。

### 接线员篇

#### 一、接线员重要守则
1为来电者保守秘密
2尊重来电者选择的自由，不替对方做决定
3坚持首问责任制，如需后续服务，应当妥善交办
4必要时果断进行危机干预或转介
5用语文明规范，决不与来电者发生言语冲突
6不利用咨询关系谋取私利

#### 二、接线员处理来电的工作步骤和要求
步骤（1）接听
1、 及时接听，勿让铃声超过三遍，迟接电话须表示歉意。
2、 接线员接听热线应当使用文明规范的首问语、过程语和结束语。
3、 接线过程中应当讲普通话。但在少数民族聚居地区或来电者只能使用方言的情况下，本着有利于工作的原则，可使用方便沟通的语言，必要时应准备翻译。
4、 用语礼貌、适度，语气亲切温和，杜绝工作忌语。
5、 集中注意力，倾听并做好适当回应，切实了解并引导来电者顺利表达诉求。
6、 掌握适当的接听时间，尽量控制在40分钟以内，使用适宜的结束语。

步骤（2）记录
1、 接线员有责任在工作表格（见附录一到附录五）中完整、准确地记录来电者个人基本信息、联系方式、反映的主要问题和诉求，以及对来电者的答复、案件处理结果以及其他相关信息。
小提示：
- 不清楚的字、地名或人名应耐心详细地询问，复述时语速适当放慢，并核对准确。
- 常见妇女儿童权益问题的咨询要点请参考指南第三部分内容。
2、 上报给管理员进行处理的，应明确记录责任人的转移。
3、 案件从接听到完成处理的全过程，每个步骤的工作均应有记录体现。

步骤（3）研判和分级
1、 接线员应通过提问引导，尽量了解来话者全面情况，把握来电者真实的意思表示，对来电者拨打热线的目的和主要诉求做出总结判断。
2、 对案件重要程度进行初步分级，给予相应的处理：
    一级：一般案件，包括普通的咨询类、意见建议类、揭发控告类和申诉求决类。由接线员负责解答（参考第24页＂三、案件分类处理＂）。
    二级：重要典型侵权案件，包括：1）严重侵害妇女儿童权益的案件，2）具有普遍性、苗头性的侵害妇女儿童权益问题，3）突发网络舆情，4）其他需要妇联组织进行重点协调关注的情况。由接线员作初步回应（接听、记录，表示关注并告知可同时向有关部门反映）后，报管理员协调处理。

小提示：
- 妇联重点关注的妇女权益问题可参见＂附录三：12338热线问题类别分类统计表＂
- 三级：危机情况紧急案件，包括表露出自杀、自伤意图，或者正遭受暴力、拐卖等非法侵害的，接线员在接听、记录主要信息后，应迅速作出判断，启动紧急案件处理预案，与管理员协同处理。
小提示：
- 具体问题的处理可参考指南第三部分＂三、危机干预类：自杀问题＂。

步骤（4）解答
1、 对情况清楚、政策明确的问题，接线员应即时对来电者进行有针对性的解答，解答内容应当准确、清晰和完整。
2、 不应随意回答不知晓或不清楚的问题。可转接相关专家、志愿者，或者告知来话者可能给予回复的时间。接线员将问题记录下来后，查询清楚再作回复，如需报告管理员，应按照工作程序流转，尽快将处理结果回复来电者。
3、 来电者要求接线员对具体问题表态的，接线员答复要原则、严谨，不要轻率下判断。

步骤（5）上报
接线员判断属于重要典型侵权案件（二级）、危机情况紧急案件（三级）的来电，应进行初步回应，做好有关记录并上报管理员处理。

步骤（6）跟踪、反馈
1、接线员负责对转接给专家、志愿者答复的案件进行跟踪，了解来电者是否获得了满意的答复或适当的服务。
2、上报管理员处理的案件，由管理员负责对转介或分流到其他职能部门、合作单位、上级妇联的案件处理情况进行跟踪了解。必要时应积极协调，与有关单位共同促进问题的解决。
小提示：
维护妇女儿童权益是妇联组织的职责，也是全社会的共同责任，需要职能部门各司其职。

步骤（7）回访
12338 热线应有专人对来电者进行有选择的回访，重点是转介出去的案件。回访的目的是评估工作，发现问题，及时改进。

回访应先做自我介绍，并核实来电者身份和反映的问题，通过回访了解来电者对案件处理结果是否满意。不满意的，应当根据案件事实和相关政策法律规定对其做好解释工作和思想工作，如确有必要，可上报管理员进一步给予针对性服务，确保来电者得到实际有效的帮助。

#### 四、沟通用语参考

一、首问语

**目的：从接听起与来电者建立良好的关系**

规范用语举例：

1. “您好，这里是 \*\*（地区）12338 热线，请问我能为您做什么？”
2. 如逢节日，可向来电者致以节日问候，如：“新年好，\*\*（地区）12338 热线人员将热诚为您服务。”
3. 在答复邮件、回访电话时，首先应自我介绍，然后核实咨询者身份和咨询问题。

二、沟通过程

**（一）目的：礼貌、平和地互动，保证沟通顺畅。**

4. 多使用文明礼貌用语：“请问”，“请讲”，“请稍等”，“很抱歉”，“让您久等了”，“请原谅”，“谢谢”，“不客气”，“再见”。

**（二）目的：共情，让来电者感觉被关注和理解**

5. 复述来电者的话，使他们确认自己的情况得到了专注的倾听：“你说你感到没有出路，不知道怎么办。”
6. 叙述感受到的来电者的情绪，“我感觉您很着急”、“我听到你说很难过，是这样吗？”。
7. 引导来电者了解自己的感受：“您当时是什么感觉？”

**（三）目的：适当回应，并促进对话的开展**

8. 尽量针对事件的人物、地点、事件、经过等因素进行提问，并且使用开放式提问，从而鼓励来电者提供更多的信息，避免仅给予简单的肯定或否定回答：“事情是怎么发生的？”“然后发生了什么？”“当你感到担心时，你会怎么做？”“你的感受如何？”
9. 当需要进一步澄清相关情况和致电者的感受时，可复述来电者说过的话，或者对其描述的复杂情况进行归纳总结：“你刚才说，爸爸一回到家里就会打你妈妈，你也很害怕他会打你。这种情况从之前就有过，但在爸爸开始喝酒以后就更严重了。我理解的对吗？”

**（四）目的：澄清、确认某些事项，以及保证记录和判断准确**

10. 当来电者表述比较含糊，要作适当判断及引导，并取得对方确认：“您反映的是……的问题吗？”
11. 当来电者没有清楚地表达要求或存在疑问时，应该对方提出主要诉求，防止发生误会或差错：“请问您最希望解决的是什么问题？”“您拨打我们热线最主要的目的是什么？”
12. 当来电者语速过快，言辞过于激烈时，“对不起，您能讲慢一点吗，我正在记录。”
13. 当来电者表述的抽象的概念太多时，可请其举个例子说明或者通过提问确认他的话的真实含义：“请你举一个例子说明好吗？”“你的意思是不是说……”

**（五）目的：有效应对来电者的沉默，促进思考，不中断话题**

14. 沉默可能是来电者难以启齿，或情绪激动，也可能是需要时间来思考，接线员应允许对方沉默，并给予适当回应：“我一直在听”，“没关系，让我们静一会儿，一起来想一想刚才讨论过的内容。”

**（六）目的：让来电者了解热线正在为他做的工作，保持耐心等待**

15. 当需要对方等待时：“请稍等”，“请不要挂机，我为您查询相关政策（信息）”，“对不起，您咨询的问题我需要转给其他咨询师，请您稍等”。
16. 中间等待时间较长时，要注意与对方保持联系，中断时间不能太长。回复时应致歉：“对不起，让您久等了”。

**（七）目的：让来电者得到反馈，理解热线的工作范围**

17. 来电者对接线员答复内容不理解，提出异议时：“现在的相关法律政策 / 相关部门是这样规定的，我也很同情您，您的意见和建议我已经记录下来了，我们会转达给 \*\* 部门，您也可以直接与 \*\* 部门沟通，电话是 \*\*”。
18. 来电者对接线员答复内容表示理解时：“谢谢您的理解与支持”，“很高兴为您服务”，“欢迎您再次拨打 12338”。
19. 当不能立即答复来电者时：“对不起，我目前很难回答您的问题，但我已经记录下来，咨询专家后会尽快给您回复”。

三、结束语

**目的：让来电者对通话留下良好的印象，不论问题是否得到解决，都能够感到尊重和被重视**

20. “感谢您拨打 12338 热线。”
21. “请问还有什么可以帮助您？”
22. “不必客气，这是我们应该做的。”
23. “感谢您提出的宝贵建议，我们将及时反馈给相关部门。”
24. “再次感谢您对我们工作的关心和支持。”

#### 五、与儿童沟通的原则

《国际儿童热线咨询工作指南》指出

致力于儿童权利提升的热线机构，都应采用以儿童为中心的工作方式，主要原则包括：

- 1、聆听儿童倾诉的内容，并尊重他们的意见
- 2、与儿童交谈，并适时提供与其身心发展与理解能力相符的信息与知识
－3、着重关注儿童的需求与权利
－4、试图从儿童的角度理解世界
－5、始终将儿童看作服务的主要对象
- 6、既把儿童看作独立的个体，也把他／她看作班级和团体中的一员
- 7、鼓励儿童参与的积极性，帮助儿童培养自身能力，并赋予他们做决定的权利

并建议 为儿童服务的热线工作人员必须具备十项核心素质，例如：有良好的工作态度、价值观和同理心；有能力判断并评估拨打热线的儿童和青少年是否处于危险中；了解在目前阶段，当地儿童和青少年有可能面临的常见问题；了解热线与其他机构组织的关系，以便在必要时有效开展转介服务；等等。（《国际儿童热线咨询工作指南》的有关内容节选见《参阅资料》）

重要提示：
12338热线来电者中儿童比例很小，接线员应注意培养自身对儿童权利保护问题的观察力，从成人咨询中发现儿童在其中的处境和需求，尤其是对涉及家庭、婚姻的咨询。接线员可询问和记录三个问题：

1、 你（来电者）反映的事件中涉及到儿童吗？
2、 儿童在事件中属于怎样的位置？当事人还是旁观者？
3、 儿童从这事件中受到了什么影响？（身体方面、心理方面）。

#### 六、接线服务禁忌十项行为

1． 轻易打断来电者讲话，或者转移话题
2． 接通电话后仍在闲谈或做与工作无关的事
3． 精神萎靡，态度不耐烦
4． 傲慢无礼，语气生硬
5． 责问、反问或训斥来电者
6． 不懂装懂，敷衍推诿
7． 解答过程中使用过多专业语言
8． 与来电者针锋相对或发生争执
9． 来电者挂机前主动挂机
10． 利用咨询关系满足自己的精神或物质需求

#### 四、管理员工作流程说明

在热线案件的办理流程中，管理员主要负责对接线员上报的案件做分别处理：

1．转介

对不属于妇联职责范围或者依靠妇联自身力量无法解决的，但又确实需要妇联组织进行重点协调关注的（二级）案件，应作转介处理，并告知来电者向有关主管部门提出。必要时可以按工作程序以妇联名义发函协调相关部门、合作机构和服务实体共同解决。转介时必须向转入部门或单位提供已了解的来电者的完整信息。

管理员判断为不需妇联重点协调关注的一般案件，可不予转介，但应要求接线员按照工作规则答复来电者，或告知来电者向主管部门提出。

管理员对来电者涉及其他相关部门的一般性意见建议，不需转介的，可予以转告，并作好记录、备案。

2、分流

对属于妇联职责范围的案件，需要在妇联系统内作分流处理，采取自办、会办、交办或转送形式，做好个案办理工作。

自办：由热线或主管的妇联权益部门办理；
会办：由合作的专家、法律援助机构、心理咨询机构办理；

交办：属于下级妇联职责范围的重点案件，按规定程序附函交办，并做好跟踪督办工作

转送：属于本级妇联其他部门或上级妇联职责范围的案件，按规定附函转送

3．跟踪

定期与办理部门联系协调，及时了解、掌握案件办理的进展情况和处理结果。

对不及时处理的情况进行督办、催办，确保来电者的诉求得到及时妥善处理。

4．反馈

自办或转介、分流到其他部门办理的案件，应当适时对案件的处理情况进行反馈，反馈过程中应当征求来电者意见或通过反馈获取新的线索，在案件查实有处理结果或方案后及时将办理信息告知给来电者。

- 般随母方生活。但在母方三种情形下可随父方生活。
- 两周岁以上未成年子女，父母均要求争取抚养权的，可帮助来电者分析其符合法定优先考虑的有利条件。

（二）家庭暴力问题

对接线员的基本要求：不要责备受暴者，避免她们受到二次伤害；尊重受暴妇女的决定

案件记录要点：
家暴发生的时间、地点，暴力形式和情节，受暴人伤情，可证明的人，当事人诉求。填写《家庭暴力统计表》

家庭暴力咨询的一般程序：

－1、评估来电者人身安全的状态。了解来电者目前的处境，有无来自施暴者的危险，或是自身处于极度绝望、有可能自杀的状态。
－2、倾听。耐心地听受暴者把话说完，通过诉说，情绪也会趋于缓和，有利于接下来的沟通。
－3、给予来电者情绪的抚慰和心理支持。与之共情，站在她的立场上理解她的想法、行为和她面临的困难。
－4、帮助来电者理清思路，寻找理性的解决办法。通过提问，引导她思考，发现自己的力量，即使没有男人在身边，她和孩子同样能够生活。例如：他都不给你生活费，你和孩子靠什么过日子？你怎么安排家里的生活，而且维持得还不错？
－5、引导来电者挖掘自身资源，提高自信心。共同分析，帮助她看到自身的优势。
－6、强化受暴妇女的主体意识和权利意识
－7、自办或转介。可通过妇联组织的维权网络或与其他部门合作给予帮助。注意：如评估人身安全属于高危情况，应及时通报公安机关和社区／村，进行转介。如受暴妇女儿童有心理咨询需求，可为其联系心理咨询师。

小提示：
－提醒固定证据。如将伤情拍照；受到家暴后应尽快去医院就诊，保留病历，暴力严重的可以进行伤情鉴定；拨打110留下报警记录，警察出警到现场的，可主动要求做笔录。
－应询问孩子是否遭受家暴，或家暴行为是否被孩子目睹。从保护儿童身心健康的角度，厘清一些女性为了孩子忍受暴力的认识。
－人身安全第一，可与来电者讨论暴力发生时如何离开，有效地保护自己和孩子。
－离婚期间受暴方可向法院申请人身保护令。

相关知识：我国法院开展人身保护令工作进展
2008年3月，最高人民法院发布了《涉及家庭暴力婚姻案件审理指南》，首次提到＂对被害人采取保护性措施，包括以裁定的形式采取民事强制措施，保护受害人的人身安全＂，俗称为人身保护令。自江苏省无锡市崇安区法院发出全国首例人身保护令以来，全国各地法院相继进行了人身保护令的试点，广东、湖南、陕西和重庆等省市的高院还陆续出台了关于保护令的暂行规定。日前，福建莆田市城厢区法院与公安机关联动，依法对一名违反＂人身保护令＂的男子予以行政拘留，这是全国第一例由公安机关对违反保护令的施暴方进行行政拘留的案件。
－可以委托所在社区妇联、村妇女主任对该家庭进行跟踪，对施暴者进行批评教育。
－切忌：询问受暴妇女＂为什么挨打＂，这是在暗示她对遭受家暴是有责任的，事实上无论因为什么，使用暴力都是错误的。

（四）儿童性侵害问题

小提示：
12338来电中，反映儿童性侵害问题的一般是父母、家长或老师，在确定或不确定孩子是否遭到性侵害的时候，向热线咨询如何处理这类事件。

咨询要点：

－接线员首先应向来电者传达两个理念：相信孩子所说的话；遭受性侵害不是孩子的错。
－了解儿童遭受性侵害案件的特点——不一定是被＂暴力＂占有，因为对儿童造成性侵害的许多来自于周围的熟人——老人、亲戚、同学、邻居等，采用物质引诱、假意示好等办法，或是说不准告诉家人，否则对家人不利等威胁言语。
－处理儿童性侵害案件的一般程序：
    （1） 维护隐私：处理时，应维护孩子的隐私与尊严，顾及孩子的感受。让孩子远离侵害人，不要让孩子反复讲述被伤害的过程。避免受到二次伤害。
    （2） 了解事实：鼓励孩子说出实话，并给予支持与安全感。做好安慰工作，在生活和学习上更加关心孩子。
    （3） 危机处理：（1）保存受害证据。（2）安排孩子至医院检查、治疗。（3）向公安机关报警。（4）带孩子接受心理辅导。
    （4） 心理支持：（1）倾听、接纳孩子的感受，相信孩子所说的事情真相。（2）告诉孩子这件事他没有错，他还是好孩子。（3）表达父母的关心，给他温暖与安全感。④学校老师，特别是心理辅导老师，应配合辅导。

辨识儿童遭到性侵害的方法：

1、 生理方面：（1）生殖器官（包括阴部、肛门、尿道）有受伤、疼痛、出血或感染症状。（2）行走或坐卧时感到不适。（3）处女膜破裂或两腿内侧红肿、瘀伤现象。
2、 行为方面：（1）异于平常的情绪反应，如恐惧、退缩、攻击等。（2）对

异性或特定的成人反应异常，不是过分亲昵，就是极度害怕逃避。
（3）极力掩藏生殖器官等身体部位。
预防儿童性侵害的措施（最好不要对第一次来电反映孩子遭受性侵害的家长谈论这部分知识，避免对方产生被责备的感受）：

1、 指导儿童合宜的穿着和言行。
2、 指导儿童正确的性观念：任何人提出的性接触，都要断然拒绝。
3、 让儿童知道身体某些部位是属于个人隐私，别人是不可以随便碰触的。如泳衣覆盖的地方就是隐私部位。

5、 对于不当或不舒服的身体接触，要勇敢地说＂不＂。
6、 陌生人或熟人都可能是性侵害的加害人，应避免独自在无人的场所逗留。

（五）劳动和社会保障权益问题

1、 就业性别歧视
咨询要点：
- 判断来电者反映的问题发生的原因
- 出于性别原因拒绝录用妇女或提高对妇女的录用标准的，属于就业性别歧视问题，热线应予以受理、转介并协调跟进。
－用人单位对男性、女性没有区别对待的，属于一般劳动争议和劳动纠纷，可告知来电者向主管的劳动行政部门反映。

相关知识：
我国法律规定，妇女享有和男子平等的就业权利，除国家规定不适合妇女的工种或岗位外，不得以性别为由拒绝录用妇女或提高对妇女的录用标准。

女职工禁忌从事的劳动范围包括：

（一） 矿山井下作业
（二） 体力劳动强度分级标准中规定的第四级体力劳动强度的作业
（三） 每小时负重 6 次以上、每次负重超过 20 公斤的作业，或者间断负重、每次负重超过 25 公斤的作业
2、 女职工特殊劳动保护
咨询要点：
－法律规定，处于孕期、产期、哺乳期的女职工受到特别保护，用人单位不得随意解除劳动合同。对女职工反映的此类问题，热线应受理并转介。
－生育或流产的医疗费用以及生育津贴，已参加生育保险的，由生育保险基金支付；未参加生育保险的，由用人单位支付。
－对用人单位不落实女职工特殊劳动保护的一般纠纷，原则上建议女职工与单位协商解决，热线可帮助其反映和调解。
相关知识：
1．产假待遇：女职工生育享受 98 天产假。其中产前可以休假 15 天；难产的，增加产假 15 天；生育多胞胎的，每多生育 1 个婴儿，增加产假 15 天。
女职工怀孕未满4个月流产的，享受15天产假；怀孕满4个月流产的，享受 42 天产假。
2．哺乳期待遇。对哺乳未满1周岁婴儿的女职工，用人单位不得延长劳动时间或安排夜班劳动。用人单位应当在每天的劳动时间内为哺乳期女职工安排1小时哺乳时间；女职工生育多胞胎的，每多哺乳1个婴儿每天增加1小时哺乳时间。
3、 职场性骚扰
咨询要点：
－遭受性骚扰不是女性的错。错的是实施性骚扰的那个人。
- 在劳动场所，用人单位有责任预防和制止对女职工的性骚扰。
- 用人单位一般均设有内部的职工投诉处理机构，女职工可首先向其报告，要求制止和惩罚行为人。
- 女职工可报警求助，也可向用人单位的主管部门投诉性骚扰。
- 对于造成严重后果的职场性骚扰行为，接线员应当上报管理员予以转介并协调处理。

4、未成年工特殊保护

我国法律禁止雇用不满十六周岁的未成年人，并对年满十六周岁、未满十八周岁的未成年工予以特殊保护，如有热线来电反映此类违法行为，应告知其报警，并立即转介公安机关。

相关知识：
针对未成年工处于生长发育期的特点，以及接受义务教育的需要，国家法律规定要对未成年工采取特殊劳动保护措施，禁止安排未成年工从事矿山井下、有毒有害、国家规定的第四级体力劳动强度的劳动和其他禁忌从事的劳动（具体见原劳动部1994年颁布的《未成年工特殊保护规定》）。用人单位应当对未成年工定期进行健康检查。

（六）拐卖妇女儿童问题

咨询要点：

- 安抚来电者的情绪
- 询问并准确记录被拐卖人的基本信息，包括姓名、年龄、性别、身份证号、现地址、联系方式、原住所、被拐卖的经过等。如果来电者是替他人求助，要详细记录来电者的基本信息。
－对于新发案件，应马上转介到公安机关，进行协调跟进，并请来电者迅速报警。公安机关已建立了儿童失踪快速查找机制和侦办拐卖儿童案件一长三包责任制，对儿童少女失踪案件立案侦查。

- 此类问题必须有跟踪，有回访，转介必须及时。
- 寻找本地公安机关打拐办联系方式。

相关知识：
2010年11月3日，全国妇联与公安部联合发出通知，建立来历不明疑似被拐妇女儿童和被解救妇女儿童信息通报核查机制。通知要求，各级妇联组织要充分发挥密切联系妇女群众的优势，依托建在2000多个县妇联的12338维权热线、建在街道、乡镇的妇女维权站（点）及建在村和社区的妇女之家，对于涉及拐卖妇女儿童的举报、投诉，以及发现来历不明、疑似被拐的妇女儿童，及时将有关信息通报同级公安机关或拨打110报警。各级公安机关接到妇联组织通报的信息后，要立即部署核查，从中发现拐卖犯罪线索，及时立案侦查，抓获拐卖犯罪分子，解救被拐卖妇女儿童，严厉打击拐卖犯罪。其中，对来历不明、疑似被拐儿童，要及时采血检验后录入全国打拐DNA信息库。

通知规定，各级公安机关要将解救的被拐卖妇女儿童信息及时通报同级妇联组织，加强协作配合，共同采取措施加强对被拐卖妇女儿童的救助、康复工作。基层妇联组织要主动了解妇女儿童的需求，加强与社区相关部门协调联动，开展走访关爱、教育培训、心理康复等多种形式的维权服务，注意保护被解救妇女儿童的个人隐私，帮助被解救妇女儿童尽快回归家庭、重返社会。

（八）财产权益问题

1、 继承纠纷
咨询要点：
- 女儿与儿子同为第一顺序继承人，享有平等的继承权。
- 可继承的只是被继承人死亡时遗留的个人合法财产，对其中本来属于他人如妻子、子女的部分不能作为个人财产进行分割。
－遗产分割要根据权利义务相一致原则，原则上均分，但是对少尽、不尽扶养赡养义务的，可以少分、不分。

相关知识：
1） 享有法定继承权的主体：
第一顺序：配偶、父母、子女；
第二顺序：兄弟姐妹、祖父母、外祖父母；
第一顺序有继承人的，第二顺序不继承。
丧偶儿媳、女婿对公婆、岳父母尽了主要赡养义务的，是第一顺序法定继承人。
代位继承：被继承人的子女先于被继承死亡的，由被继承人的子女的晚辈直系血亲代位继承。代位继承人一般只能继承他的父亲或母亲有权继承的遗产份额。
2） 即使有遗嘱，亦应为胎儿保留必要份额；被继承人生前扶养的无生活来源又没有劳动能力人的，亦应适当分得遗产

2、 农村妇女土地及相关权益问题
咨询要点：
－首先应记录来电人基本信息、户籍地、经常居住地、婚姻状况、失去土地或相关经济权益的时间、原因（是征地还是婚姻变化？）和形式（由于村规民约、村委会决议或村民代表大会决议？），是否尽了村民义务，目前的生活主要来源和现状。应明确了解来电人对土地权益的具体诉求，如划拨宅基地、征地补偿安置还是集体经济收益分配等其他的村民待遇，其子女的利益是否有保障。
－我国农村土地承包法第六条明确规定，农村土地承包，妇女与男子享有平等的权利。承包中应当保护妇女的合法权益，任何组织和个人不得剥夺、侵害妇女应当享有的土地承包经营权。
－妇女应当按照权利义务相对应的原则获得保障。因目前大多数地方以户籍所在地为主要依据，确认集体经济组织成员资格，接线员可对问题做分类答复处理：
    1、 对在户籍地长期居住且依法尽了村民义务，但因离婚、丧偶或农嫁非等原因失去土地及相关权益的，应帮助协调处理，支持其向基层政府和农业部门反映，争取权益。
    2、 对在居住地已拥有相应土地权益或收益分配，但因户籍地征地拆迁补偿又回来要求享受权利，且无依据的，应做思想疏导和政策解释，请来电者到其他有关部门咨询。
    3、 对来电者反映村集体通过制定违反男女平等原则的村规民约、村委会决议或村民代表大会决议，侵害妇女土地权益的问题，应进行收集整理，向当地乡镇政府、县级民政部门以及上级妇联反映，要求纠正。

小提示：
农村妇女土地问题发生比较普遍，涉及传统习俗、法律政策、利益分配等多方面原因，每个案件的具体情况也不同，需要进行细致的分类处理。各级妇联一直在为保障农村妇女土地权益呼吁建议，推动完善法律政策，但是难以在短时间内得到根本的解决。

对于各地12338热线来说，不能因问题难以解决向来电者传递无奈与无助的情绪信息，要在和来访者一起分析应对具体问题的同时，做好农村妇女土地侵权案例的收集、研究和报送，努力帮助协调解决典型个案、推动地方政策出台，为全国积累和贡献有益经验。

3、 城市房屋拆迁补偿
咨询要点：
－补偿客体有三个方面：（1）被征收房屋价值的补偿；（2）因征收房屋造成的搬迁、临时安置的补偿；（3）因征收房屋造成的停产停业损失的补偿。
－补偿标准不得低于房屋征收决定公告之日被征收房屋类似房地产的市场价格。
－国家规定的基本补偿政策
    1． 被征收人可以选择货币补偿，也可以选择房屋产权调换。被征收人选择房屋产权调换的，市、县人民政府应当提供用于产权调换的房屋，并与被征收人计算、结算被征收房屋价值与用于产权调换房屋价值的差价。
    2． 因征收房屋造成搬迁的，房屋征收部门应当向被征收人支付搬迁费；选择房屋产权调换的，产权调换房屋交付前，房屋征收部门应当向被征收人支付临时安置费或者提供周转用房。
    3． 对因征收房屋造成停产停业损失的补偿，根据房屋被征收前的效益、停产停业期限等因素确定。
    4． 实施房屋征收应当先补偿、后搬迁。对被征收人给予补偿后，被征收人应当在补偿协议约定或者补偿决定确定的搬迁期限内完成搬迁。任何单位和个人不得采取暴力、威胁或者违反规定中断供水、供热、供气、供电和道路通行等非法方式迫使被征收人搬迁。
－拆迁问题的政策性较强，此处仅列出国家一般规定，各地热线请可查看当地法规、政策补充至回答要点（可以联系本地城市拆迁主管部门）

### 三、危机干预类：自杀问题

自杀干预的原则是分秒必争，主动参与指导。
对接线员基本要求：缓解来电者的心理压力，努力使其打消自杀念头。咨询要点：

（1） 充分表达理解与关怀，充分肯定来电者来电话咨询是作为明智的选择，明确而清楚地告诉对方：＂自杀是解决问题的一种方式，但不是最好的方式，让我们来共同寻找解决问题的建设性方式＂。
（2） 积极倾听，用多种提问了解情况，澄清问题。需要了解的情况包括：使他决定自杀的当前诱因是什么，其严重程度是客观现实还是主观臆断，他采用了什么样的对策，他是否有过自杀经历，是否精神病人，如有必要还要了解他个人经历中的创伤性体验，如果有可能还应了解他的地址以便必要时通知其家人。
（3） 与来电者重点讨论他所面临的创伤性事件，判断此事件的客观现实与其主观反应是否对等。
如果他存在认知障碍，应针对其问题努力排除其认知障碍；如果创伤确是客观事实，就要帮助他分析为什么他以前采用的方法未能奏效。
（4） 运用发散性思维协助来电者寻找解决问题的办法，强调用建设性方式解决问题。
（5） 激发来电者对亲友的牵挂和责任感
要非常具体地激发来电者，如＂如果你以这种方式了结自己，想像一下你的亲友的感受，他们除了痛苦外，会不会因此而非常自责？＂
（6） 帮助来电者发掘社会资源
（7） 鼓励来电者再给自己一次机会
可与来电者一起把商定的建设性方案具体化、可操作化，并督促来电者去作尝试。
（8） 与对方坦诚地讨论自杀的方式及其后果
－特别提示
只要有可能，要想办法打听到对方的地址，并和有关方面如警察等联系，以便可以采取紧急措施，从而有效制止其自杀行为。
