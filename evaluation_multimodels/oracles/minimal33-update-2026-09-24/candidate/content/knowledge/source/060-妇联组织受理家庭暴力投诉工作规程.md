# 妇联组织受理家庭暴力投诉工作规程

全国妇联权益部 2018年

## 正文

为加强县以上妇联维权机构和信访窗口接处家庭暴力咨询和投诉工作的规范性，切实履行妇联组织预防和制止家庭暴力的法定职责，依据《中华人民共和国反家庭暴力法》有关规定，制定以下工作规程。

### 1．

根据《妇联组织信访工作规定》，向社会公布接受咨询和投诉机构的通信地址、电子信箱、投诉电话、工作时间等，接受群众关于家庭暴力的来信、来访、热线咨询和投诉。指导基层维权服务站、家庭暴力投诉点、危机干预中心等深入群众宣传讲解反家庭暴力法，告知妇联维权服务渠道及其他救济途径，提高群众知晓率。

### 2．

接受并处理乡镇和村、社区妇联对所在地区家庭暴力隐患和问题的报告，指导其在参与矛盾纠纷排查或开展婚姻家庭矛盾纠纷化解等工作时，重点关注辖区内具有家庭暴力危险的家庭情况，关注贫困、残疾、留守、单亲等家庭，增强对家庭暴力案件的发现报告意识。

### 3．

根据《加强妇联组织舆情分析、研判和应对的工作意见》，落实属地处理原则，对媒体曝光的家庭暴力案件及时跟进，全面掌握情况，主动了解受害妇女维权需求，依法提供维权服务。

### 4．

妇联信访窗口在接待处理群众婚姻家庭权益等咨询和投诉时，要增强发现家庭暴力风险的意识，注意观察来访者的外貌表情、询问家庭成员关系、心理感受等，如有伤情或表现出恐惧的，要重点面谈评估，作进一步识别。

### 5．

在工作中发现无民事行为能力人、限制民事行为能力人遭受或疑似遭受家庭暴力的，应当及时向公安机关报案。

### 6．

接到家庭暴力投诉后，应当按照“登记、危险评估、分级处理、结案存档、跟踪回访”的程序进行处理，并不断完善个案管理流程。投诉地与受害人居住地、家庭暴力行为发生地不一致的，由投诉地妇联根据个案实际和工作需要协调联系，进行转介。必要时，报请上级妇联组织协调处理。

### 7．

登记家庭暴力投诉时，应当按照“妇联组织信访信息管理系统”的要求，对信访人信息、家庭暴力形式、起因、结果、当事人求助意愿和办理过程、处理情况进行详细记录。定期对投诉进行专项统计上报，并对家庭暴力问题现状和反家庭暴力工作情况作出分析，提出建议。

### 8．

受理家庭暴力投诉后，要详细了解个案基本情况，询问受害人的真实求助意愿，对其问题作出判断，并根据受害人的危险自评以及现实情况作出危险评估。必要时，应通过其家庭、所在社区和社会支持系统收集相关资料。

### 9．

对不同危险级别的家庭暴力投诉应当作出分级处理。对于初次遭受家庭暴力且情节较轻的，可运用法律咨询、心理咨询、婚姻家庭关系指导和纠纷调处、社工服务、困难帮扶等方式，为受害人及其家庭提供帮助，并告知可向公安机关报案，由公安机关依法对加害人进行批评教育或出具告诫书。

### 10．

对于已经造成人身伤害或具有现实危险性的，以及情节较轻但多次遭受家庭暴力的，应当协助受害人反映诉求，支持其报警求助、进行家庭暴力伤情鉴定、申请人身安全保护令、法律援助和庇护救助等。

### 11．

对于严重的特别是高危致命危险的家庭暴力投诉，或者本人及其亲属面临人身安全威胁的，不能劝和或调解，应当及时报告当地公安机关和上级妇联。同时制定综合性的个案维权服务方案，确定承办人员，与公安、民政、法院等其他部门和机构开展有效合作，共同为受害人提供服务。

### 12．

受害人是无民事行为能力人、限制民事行为能力人或者因受到强制、威吓等原因无法申请人身安全保护令的，可代为申请或指导其近亲属申请。符合条件的，纳入“中国妇女法律援助行动项目”予以支持。

### 13．

对已结案的家庭暴力投诉，可通过电话或约见进行回访，并确认受害人在安全环境中反映真实情况。对于严重的家庭暴力案件，应当回访并增加回访次数。可支持专业组织开展受害人心理支持小组或家庭成长小组等后续服务，探索对加害人的心理辅导工作。

### 14．

维权服务完成后，承办人应当将相关文档如投诉登记表、危险预测量表、相关法律文书、回访记录等收集归档，做好存档工作。需要时，可依法提供作为受害人遭遇家庭暴力的证据材料。

### 15．

妇联信访工作场所应当放置反家庭暴力的宣传品、播放宣传视频，可采取引入专业组织、招募社会志愿者、培育有关社会组织和相关服务机构等方式，联系和团结社会力量共同做好反家庭暴力工作。

### 16．

妇联维权干部应当贯彻男女平等的宪法原则，增强识别和处置家庭暴力的能力，破除“打老婆是家务事”“棍棒底下出孝子”等传统观念，深刻认识家庭暴力的实质是控制，耐心细致做工作，不指责受害人，教育引导妇女群众依法理性表达诉求，帮助其依法维权。妇联组织应当关心妇联维权干部的心理健康，通过督导、调适等，给予有效支持，提高工作水平。

#### （2）家庭暴力案件危险性评估量表使用说明（试用）

使用危险评估量表的目的，在于了解亲密关系暴力事件的危险情形，辅助工作人员了解被害人的危险处境，也可以提醒被害人对自己的处境提高警觉，避免受到进一步伤害。

一、使用对象

1. 因为亲密关系暴力事件受伤害来报案、就医或寻求协助之人，不论男女。
2. 亲密关系指配偶、前配偶、同居、曾同居或交往亲密的男女伴侣。

二、填答方法

为避免被害人在情绪下填写，请在接案后填写本表前先安抚被害人情绪、同理会谈并填写接案登记表后，再行填写为佳。

1. 填答应遵守以下基本流程。
2. 在提供了应急服务，办理好应办的事宜后填答。例如：阻止正在进行的施暴、送受伤者去医院救助、帮助固定证据、过来投诉，进行接待登记。
3. 工作人员向被害者说明评估目的是要让工作人员更了解当事人的危险状况，并由工作人员询问被害人评估量表的问题填答。如被害人拒填，在登记表或通报表上注明。
4. 使用自然的方式，询问相关问题。注意性别意识，不可问“为什么挨打”，不可责备被害人，避免对被害人造成二次伤害。
5. 当被害人无法清楚回答时，工作人员可加以说明，但不可引导被害人选择答案。
6. 当被害人伤势严重，或情绪不稳以致当下无法回答时，可于稍后被害人状况好转后，再联络被害人进行。若被害人情绪长期处于不稳定状况，可邀请成人家属代为作答。
7. 将内容填完整，用于事后统计分析。
8. 遵守保密原则，相关资料仅作为多机构反家暴网络工作之用，不得外传。

三、计分方式

表格包括两部分，第一部分包含9个题项，第二部分为2个特别提示题。

第一部分每题答“有”核计1分，答“否”不计分，累加后计总分。3分及以下为“低危险”，4至5分为“中危险”，6分及以上为“高危险”。选了特别提示题任一题，均为高致命危险。

四、题项内容说明

以下为各题内容说明，请工作者熟悉每一题之评估重点。

| 题目内容 | 评估重点 |
| :--- | :--- |
| 1. 他曾威胁要杀你 | 1. 可询问加害人是否曾威胁杀害她，加害人如何对她威胁、恐吓？使用何种武器或危险物品？发生频率怎样？<br>2. 着重于加害人的言语精神威胁，令被害人心生畏惧和不安。 |
| 2. 你也相信他能杀你 | 1. 可询问加害人如何威胁要杀害她？他曾经采取过何种具体行动让被害人相信自己有被杀害的危险？<br>2. 着重于被害人的感受认知，是否相信加害人有能力杀害。 |
| 3. 他控制你大部分生活 | 1. 包括经济、人身、性、家庭决策等方面。可询问是否大事小事加害人都要说了算，经济权由谁掌管？有没有限制人身自由？有没有不许外出工作或交朋友？<br>2. 着重于加害人的控制欲以及被害人是否有能力逃脱。 |
| 4. 他常常因为嫉妒而对你使用暴力（如曾说“我若不能拥有你，其他人也不能”） | 1. 可询问加害人是否很在意她与别的男人接触？是否因怀疑她而施暴？有没有因嫉妒说要杀死她？发生频率怎样？<br>2. 着重于加害人的言语精神威胁，令被害人心生畏惧和不安。 |
| 5. 他曾威胁要自杀，或尝试要自杀 | 1. 可询问加害人是否谈论过与自杀有关的话题，预言、暗示自杀，或以自杀来威胁？有没有采取过实际行动？ |
| 6. 他是否说过“要离婚或分开就一起死”或“要死一起死”此类话 | 1. 可询问被害人有没有和加害人提起过离婚或分开，当时加害人是什么样的反应？讲这样话的频率如何？<br>2. 着重于加害人的言语精神威胁，令被害人心生畏惧和不安。 |
| 7. 他曾威胁要伤害你娘家的人，以阻止你离开他 | 1. 可询问加害人除了打她，还没有说过要伤害她的亲人？有没有采取过实际行动？ |
| 8. 你认为未来的两个月内他一定会对你进行身体上的伤害 | 1. 可询问被害人是否觉得加害人会继续打她？<br>2. 着重被害人的感受。 |
| 9. 在你与他的关系变得不好后，他曾经监视你？（如跟踪、监听、翻看手机等） | 1. 是指任何人以人员、车辆、工具、设备或其他方法持续性监视、跟踪之行为。<br>2. 可询问加害人有没有跟踪、监视或窥视她，比如守在下班的路上？打电话至工作场所？经常性的翻查加害人的通话记录和短信？开车跟踪她？唆使他人进行跟踪？<br>3. 着重加害人有强烈控制被害人的行为，而造成被害人害怕、恐惧或严重困扰。 |
| 特别提示题1. 他曾有使你不能呼吸的行为（如勒脖子、压头入水、用枕头闷等） | 1. 了解加害人是否曾运用某种方式让被害人感觉无法呼吸，如果有发生过，可接着问什么方法？<br>2. 着重于行为的已发生，并非停留在恐吓的程度。 |
| 特别提示题2. 他曾有除了使你不能呼吸以外的其他明显的致命行为（如推下楼、灌毒药、泼硫酸、泼汽油等） | 1. 了解加害人是否有可能造成被害人死亡的其他行为。如果有发生过，可接着问什么方法？<br>2. 着重于行为的已发生，并非停留在恐吓的程度。 |
| 受害人对目前处境的自我评估打分 | 受害人对于目前自身危险情况的感知，由受害人在0至9分之间自由评定。 |
| 机构接待人员评估 | 当量表评定程度与接待者主观评定的程度不一致时，接待者是如何做判断的，在此注明。 |

五、备注事项

本评估量表为一线接案人员初步评估危险之用，评估结果可作为案件后续处理的重要参考，但暴力行为相当复杂，仍需在接案表上进行特别注记：

1. 当场所见事项说明：接触被害人当时的情境，如被害人恐惧情形、被施暴情形、加害人威胁情况、施暴现场所见情形、当事人的态度、当事人的生活状况等。
2. 工作人员感知到的影响安全的情形：受暴的历史情况、受暴频率、受暴部位、严重度、最近一次受暴情况，暴力程度是否越来越高，被害人有没有遭受性折磨，加害人是否对小孩或非家人也施暴？加害人的压力状况，是否正在遭遇经济危机、晋升失败、失业？
3. 与反家暴网络多机构合作事项：注明对本案处理的建议，被害人之前是否求助过社会机构以及处理情况如何，提醒其他网络成员的注意事项，以及需要网络成员配合与合作的工作内容。

六、评估后的处置建议

1. 关于酗酒：若一周四天以上喝酒到酒醉则属于严重酗酒，但仍未达不喝不行，建议戒酒门诊12次。若已达不喝不行，如手发抖或不喝睡不着，则建议戒酒住院2周。
2. 关于吸毒：建议公安裁定与命令强制戒毒。
3. 精神状况：若加害人之精神状况有达混乱、失去理智或失去现实感，则建议裁定或命令住院观察或治疗至少一周。
4. 多方评估不一致：如存在受害者自我评估为低危，量表评估与接待人员评估为高危的情况，则属受害者“高危险低认知”，需要为受害者提供特别的安全策略。
5. 量表结果显示为高危，且量表第四题或第六题答“是”，则加害人属于极高致命危险的人格，加害人常有玉石俱焚的想法，应更加留意被害人及子女之人身安全，立刻启动高危机案件多机构联席会议。
