# 地方反家庭暴力规则比较

## 使用方法

本页比较20份省级地方性法规或实施办法。每项差异只在相应法域和生效期间内构成 `legal_basis`；没有列出的省份不能据此推定存在相同规则。江苏使用国家法律法规数据库2025年1月14日修正版。

## 定义与适用范围

| 差异 | 法域与依据 |
| --- | --- |
| 明列性暴力或性侵害 | 甘肃、辽宁、青海、黑龙江、重庆、江苏；分别见028第三条、030第二条、031第三条、032第三条、038第二条、086第三条。 |
| 明列经济控制或经济侵害 | 甘肃、辽宁、黑龙江、重庆、江苏；分别见028第三条、030第二条、032第三条、038第二条、086第三条。 |
| 网络手段纳入家暴方式 | 青海、黑龙江、广东、重庆等；相关定义条款在本页 `source_refs` 中列明。 |
| 极端化行为排斥、干预正常生产生活 | 新疆第二条。 |
| 曾有配偶关系参照适用 | 云南第四十九条。 |
| 监护、扶养、寄养、同居等共同生活关系参照适用 | 多地附则；江苏见086第五十四条，其他范围应逐省核对。 |

地方扩展不能反向改写国家法第二条在全国范围内的定义。

## 强制报告

地方规则普遍细化无民事行为能力人、限制民事行为能力人或未成年人受害时的报告义务。河北将“密切接触未成年人”的行业纳入；广东列入人民调解组织；贵州增加强迫婚嫁等情形。安徽本文件未见同等单列条款，不能用其他省规定补入。

## 告诫书时限与查访

多地围绕“情节较轻、依法不予治安处罚”细化告诫机制，但时限存在差异：本页有精确锚点支持的示例中，部分规定24小时，部分规定72小时，吉林规定三日或当场处理；江苏第二十八条规定对应当告诫的案件自受理报案起24小时内出具。查访期限和参与主体也不同，使用时必须先确定法域并读取当地条文。

## 人身安全保护令的地方细化

陕西明确保护令不以已经造成实际损害为前提；河北、辽宁、青海、重庆、江苏等增加禁止抢夺藏匿未成年子女、禁止查阅户籍学籍住址收入等措施，江苏还列明责令接受法治教育和心理辅导矫治；广东允许根据需要分批、多次作出保护措施。这些均是地方细化，不是全国统一措施清单。

## 庇护、特殊保护与数据协作

以下仅列具代表性的非穷尽示例：山西和重庆规定应急安置或临时庇护期限；安徽、黑龙江涉及庇护场所信息公开；吉林、重庆将终止妊娠后一定期间的妇女列入特殊保护；青海、甘肃、陕西明确保护目睹家暴的未成年人。其他法域也可能有同类规定，必须回到当地条文核对。多地建立警情统计、信息共享和信用惩戒，但具体条件和解除机制不同。

## 覆盖结论

20份地方规则均已逐份读取并纳入比较；重复的国家法规则不再生成20套节点。后续查询应先按用户所在地选择法域，再读取对应精确条文。为支持不增加胶囊字段的条件检索，江苏当前定义差异另有窄节点 [[jiangsu-domestic-violence-scope]]；该节点不得在地点未知时加载。
