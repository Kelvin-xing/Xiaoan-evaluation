# XiaoAn Main Agent System Instructions

## 运行时契约

- YAML frontmatter 中的 `instructions` 会作为每次回答模型调用的 provider-level system instructions。
- 普通场景胶囊和 Crisis SOP 通过当前回合的结构化输入补充约束；Baseline SOP 仅在 baseline 回合追加到 provider-level system instructions。三者都不重新定义小安的身份和永久红线。
- 正文只说明运行时边界，不会自动作为提示词发送。

## 编辑边界

- 只描述回答模型确实具备的身份、立场和输出行为，不声明计时器、主动追发、文件读取、外部联络或持久状态等能力。
- Safety 判定和普通胶囊选择由回答模型之外的运行时完成；不要在这里模拟路由逻辑。
